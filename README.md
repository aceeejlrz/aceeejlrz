## Featured Project

### webHookDebugger · [Live demo](https://webhookdebugger.fly.dev)
A full-stack tool for capturing, inspecting, and replaying incoming webhooks.

**Stack:** Java 21 · Spring Boot 3.5 · PostgreSQL (Neon) · Flyway · Spring Security · Docker · Fly.io

- **Fault tolerance.** Added a Resilience4j circuit breaker to keep the service responsive when dependencies fail.
- **Abuse protection.** Built per-endpoint and global rate limiting with Bucket4j and Caffeine, and rate-limited the replay endpoint.
- **Reliable UI.** Request detail view supports deep-linking and race-safe polling.
- **Deployment.** Multi-stage Docker build on a Debian-slim base, versioned schema migrations with Flyway, and production hosting on Fly.io.
- **Security.** Protected with Spring Security authentication.
